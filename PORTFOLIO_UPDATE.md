# Portfolio update rule

This repository is the public entry point for ThermalAtlas.

## Public project information

When its public description, supported platform, repository URL, release link,
screenshots or visible status changes, check the Schrotty74 GitHub profile and
portfolio for matching updates.

## Portfolio requirements

1. Keep the English and German portfolio cards and detail pages aligned.
2. Link only to verified public repository and release URLs.
3. Use only intentionally public project assets and screenshots.
4. Never publish private paths, personal data, logs, backups, credentials or
   real user data.

## Privacy

ThermalAtlas remains a local, read-only temperature monitor. Portfolio text
must not claim sensor availability, compatibility or release status beyond what
the public repository documents and what is actually verified.
